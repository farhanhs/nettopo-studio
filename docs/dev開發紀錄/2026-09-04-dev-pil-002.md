# DEV_PIL_002 開發紀錄 — 新增拓樸站點欄位與響應式容器

日期：2026-09-04
狀態：READY_FOR_QA

## 範圍

- 修正新增拓樸時 `siteId` 空值會隱性繼承目前拓樸站點的問題。
- 僅允許 `browser-local + sites loaded-empty` 以 `undefined` 建立未指定站點拓樸。
- Server/Pilot 情境若沒有可用站點，UI submit disabled，handler 仍 fail closed。
- `SiteField` 顯示明確的「未指定」或「無可用站點」，不使用 fake site id。
- IndexedDB/local `createCustomer` 與 `createTopology` 會保存使用者選定的 `siteId`，未指定則保留 `undefined`。
- Modal 保留既有結構，補上 `role="dialog"`、`aria-modal`、標題關聯、關閉按鈕標籤，並調整小螢幕/低高度下的單欄與捲動行為。
