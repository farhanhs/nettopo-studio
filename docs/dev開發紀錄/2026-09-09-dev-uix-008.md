## Scope

- 登入、reload/session restore、panel layout restore 後，Canvas 使用 workspace 實際剩餘高度，不再依賴 topbar magic-number subtraction。
- React Flow 在 shell 尺寸可量測後接收明確 `width` / `height`，避免必須先點 Inspector 才觸發正確重算。
- 初次 topology lifecycle 只做一次 measured `fitView`；selection 不進入 fit dependency，避免選設備／連線重設使用者 pan/zoom。
- PanelGroup resize 由 `ResizeObserver` 重新量測 flow shell，不 remount PanelGroup / React Flow instance。
