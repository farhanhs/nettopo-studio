# 回饋

工具不自動上傳。請在可上網時手動使用 repository 的 Beta feedback issue 範本，或交給維護者。

提供：候選版本、ZIP SHA-256、Windows build、Node/npm 與瀏覽器版本、可重現步驟、預期/實際、命令結果碼。可附用隨包合成資料重現的截圖。

不要附真實客戶、設備 IP/MAC/管理網址、帳密、token、cookie、`.state`、原始組態、未檢查的完整 JSON、現用 `.env` 或資料庫。先用安全匯出並人工檢查；仍無法去識別就只描述問題，不上傳檔案。

首輪 FAIL、BLOCKED、NOT RUN 與修正後結果會分開保存，不把回報成功視為已修正或通過驗收。
