# 資料、備份與還原

## 資料位置

拓樸保存在 `http://127.0.0.1:4317` 的瀏覽器設定檔 IndexedDB（`nettopo-studio-db`），不是 ZIP 目錄或伺服器資料庫。Chrome、Edge、不同 profile、無痕模式、其他 host/port 都是不同的資料空間。清除網站資料、瀏覽器重置、無痕視窗結束或磁碟問題都可能失去資料。停止程式不會清資料。

## 升級前的完整備份

1. 等待「已自動儲存」，確認沒有本機儲存失敗提示。
2. 選擇一張拓樸，開啟「匯出」，選「下載完整 JSON」，再次確認。
3. 到瀏覽器下載目錄確認實際檔案存在、大小大於 0，另存到自己的備份位置。畫面觸發下載不代表檔案已寫入磁碟。
4. 有多張拓樸請逐張執行。此備份只涵蓋該 Project，不是客戶主檔、其他拓樸、UI 偏好或整個工作區備份。

完整 JSON 保留 IP、MAC、位置等資料，不得公開分享；即使完整匯出也不包含明文設備憑證。沒有提供伺服器憑證備份。

## 還原

在原有「匯入」入口選擇 JSON，先看 Preview，再選擇新增、合併或取代。先用「新增」驗證舊備份；取代前再備份目前拓樸。遵守警告確認與 blocking 檢查，不可略過阻擋。取消不會寫入；不相容或格式錯誤應安全拒絕，保留原檔回報，不要手改版本號硬塞。

若瀏覽器禁止儲存或容量不足，寫入會失敗，不應視為儲存成功。排除儲存問題後再操作，確認原拓樸仍在；不要以清除 IndexedDB 作第一個排除步驟。

## 安全分享

安全 JSON／安全 CSV 會移除 IP、MAC、位置與管理網址；仍要人工檢查設備名稱等欄位是否含公司資訊。安全分享不是保留完整資料的備份。

CSV Bundle v2 ZIP 匯出固定五檔：`devices.csv`、`links.csv`、`groups.csv`、`credentials.masked.csv`、`missing-info.csv`。匯入需先自行解壓，再同時選五檔；不支援 ZIP 匯入。Masked credential 只供安全預覽，不寫回 Project 或 credentials API。本機模式不提供憑證保存。

升級保持同一瀏覽器設定檔與固定 origin，不自動遷移或清除資料。新版本啟動前先停止舊包；若格式不相容，保留備份與舊包，不覆蓋舊資料。只用隨包合成範例測試。
