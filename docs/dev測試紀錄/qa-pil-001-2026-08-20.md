## Failures / Blockers

### P0-F1 — `createTopology` cross-site error contract regression

- 測試：`tests/rbac-repository.integration.test.mjs` — `createTopology hides unknown, invisible customer and unassigned site scopes`
- 重現：`node --env-file-if-exists=.env.local --env-file-if-exists=.env --test tests\*.test.mjs`
- 預期：Site Manager 使用已知 customerId 但 unassigned target site 時，對外應隱藏 scope，回 `Resource not found` 類型錯誤。
- 實際：repository 回 `Permission denied: cannot create topology for this site.`
- 風險：可能讓呼叫端分辨「資源存在但 target site 無權限」與「資源不存在」，違反 fail-closed / anti-enumeration 方向。
- QA 處置：不修改產品；列為 QA_FAILED blocker。

### P0-F2 — Sales credential write error contract regression

- 測試：`tests/rbac-repository.integration.test.mjs` — `credential reads are masked and writes are boss-only`
- 重現：`node --env-file-if-exists=.env.local --env-file-if-exists=.env --test tests\*.test.mjs`
- 預期：Sales 可讀該 topology projection，因此 credential write 應回 `Permission denied` 類型錯誤。
- 實際：repository 回 `Resource not found.`
- 風險：讀寫錯誤語意不一致，可能讓 API 403/404 mapping 與 RBAC contract 不穩定。
- QA 處置：不修改產品；列為 QA_FAILED blocker。
