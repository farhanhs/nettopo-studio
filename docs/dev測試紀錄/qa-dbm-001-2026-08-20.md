## Blocker

`QA_DBM_001` 要求 tracked files／可用 local logs 不含 active password、完整 DSN 或候選 token。QA active-secret scan 發現 `.env.local` 目前使用中的 active password 字串也存在於以下 tracked files：

- `.env.example`
- `README.md`
- `docker-compose.yml`
- `scripts/postgres-local.ps1`

本報告刻意不揭露該 password、完整 DSN 或 token。由於這違反 secret leakage acceptance criteria，`QA_DBM_001` 不可通過。
