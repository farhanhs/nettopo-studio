## 結論

- 在 Engineer 匯入 CSV 並準備修正連線資訊時，右下角 `session-profile` 登入者資料浮動卡片覆蓋 Inspector 底部操作區。

## 第一個失敗點

步驟：

1. Engineer 登入 Pilot。
2. 建立 synthetic Customer／Topology。
3. 匯入 CSV Bundle，Apply replace 成功。
4. 切到 `連線`，選取 `QA UAT Router → QA UAT Switch`。
5. 在 Inspector 填入來源 Port、目的 Port 與速率。
6. 點擊 `儲存連線`。

預期：

- Inspector 的 `儲存連線` 應可點擊並送出 `/api/topology` POST。
- 工程師可接續建立／修正連線、檢查 route、reload、safe export 與 safe round-trip。

實際：

- Playwright 判斷按鈕可見且 enabled，但點擊被右下角 `aside.session-profile` 攔截。
- 30 秒重試後 timeout。
- 無 `/api/topology` POST 送出。

核心錯誤摘要：

```text
locator.click: Timeout 30000ms exceeded
waiting for locator('.inspector-form').last().getByRole('button', { name: '儲存連線' })
locator resolved to <button type="submit" class="primary">儲存連線</button>
<aside aria-label="登入者資料" class="session-profile"> intercepts pointer events
```
