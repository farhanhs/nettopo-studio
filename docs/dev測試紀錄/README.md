# 測試紀錄索引

此目錄只記錄測試、驗證、資料落差、自動測試規劃與測試結果。

開發實作、架構決策與程式變更請記錄在 `docs/dev開發紀錄/`。

## 文件

- `local-ui-smoke-2026-07-27.md`：本機 UI smoke test 與早期使用者回饋。
- `xinghengyi-document-topology-2026-07-28.md`：興恆毅文件生成拓樸測試、參考圖對照、資料落差與自動測試缺口。

## 紀錄原則

- 不記錄明文密碼。
- 客戶原始資料、截圖、PDF、localStorage 注入資料放在 git-ignored 的 `private/`。
- 測試紀錄要分清楚：
  - 輸入資料是否不足。
  - 解析/判斷邏輯是否錯誤。
  - app 功能是否缺少。
  - UI/版面/PDF 是否需要修正。
